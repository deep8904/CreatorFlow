# Design System Addendum — Resolved Decisions

This supplements `design.pdf`. Where the two conflict on the items below, this file wins.

## 1. Hero Display Accent (new, sanctioned exception)

A single emphasis phrase within a hero headline may use a decorative script/display accent font instead of OpenRunde, to give the headline a distinctive, non-generic feel. This is a controlled exception, not a general rule change.

**Rules:**
- Applies **only** to hero headlines on marketing pages (Landing, and comparable top-of-page moments).
- **Never** used in body copy, app UI, buttons, labels, or any in-app screen.
- **Never** more than one accent phrase per headline.
- Color: use Lavender (`#918df6`) or Iris (`#9580ff`) for the accent phrase — do not introduce a new color for it.
- Everything else in the headline stays OpenRunde per the base system.

## 2. No Index-Based Color Assignment

Do not assign a different accent color to each item in a list, row, or sequence just to differentiate them (e.g., a different color per feature card, per numbered step, per pipeline stage) unless the color carries real meaning.

**Rules that replace this pattern:**
- **Feature card icons**: always Lavender (`#918df6`), 40px circle, single color across every card — no exceptions per card.
- **Sequential/numbered steps** (e.g., "How it works" 1–4): no color-coding by index. Use a neutral treatment (Ash/Graphite number, or a single consistent Lavender circle) — the number alone differentiates the steps.
- **Status/pipeline tags** (e.g., Deal stages: Inbound, Negotiating, Contracted, Delivered, Paid): color is allowed **only where it reflects actual meaning**, using the system already defined for metrics — Mint / Mint Wash specifically for a positive/completed outcome (i.e., "Paid"), and a single neutral Fog/Ash treatment for every other stage. Do not give Inbound, Negotiating, Contracted, and Delivered each their own distinct color — they're all "not yet done," so they share one neutral treatment.

**The test to apply going forward:** before assigning a color to anything, ask "does this color mean something specific, or did I just want visual variety?" If it's the latter, use the neutral treatment instead.
